## A worked example

```python
import math

def softmax(scores: list[float]) -> list[float]:
    peak = max(scores)
    exps = [math.exp(s - peak) for s in scores]
    total = sum(exps)
    return [e / total for e in exps]

# One token asks every token "how relevant are you to me?"
scores = [3.0, 1.0, 0.5]
weights = softmax(scores)
print([round(w, 3) for w in weights])   # [0.786, 0.145, 0.069]
```

Attention is a learned, content-addressed lookup. Each token produces a query; every token offers a key; the highest-scoring keys get the weight.

<Callout type="interview" title="Interview corner">
**Why is attention quadratic in sequence length, and what did that lead to?**

Every token computes a score against every other token, so the cost of the attention matrix is O(n²) in sequence length. This put a hard ceiling on context size and motivated architectures that approximate attention — sparse, sliding-window, or recurrent variants — as well as work on key-value caching and sparse attention patterns.
</Callout>

## Quick recap

- Attention is a learned lookup over the whole sequence.
- Multi-head attention attends in several learned spaces at once.
- Position must be added explicitly — attention itself is order-blind.
