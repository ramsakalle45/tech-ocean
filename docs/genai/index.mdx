# GenAI

How LLMs work, and how to build with them in production.

Every module ends with a short assessment. Progress is tracked in your
browser only — there is no account and no server.

## Roadmap

- **Foundations** — What Are Llms, Tokens and Embeddings, Transformers
- **Working with LLMs** — Prompt Engineering, Llm Apis, Structured Output, Function Calling
- **RAG and Agents** — Chunking and Embeddings, Vector Databases, Rag Pipelines, Agents and Mcp
- **Production** — Evals, Guardrails, Cost and Latency, Fine Tuning vs Rag, Observability
- **Interview** — Top Questions, System Design For Genai, Mock Tests
