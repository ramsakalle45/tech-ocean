# How to read this book

This is a book about four things: **Python**, **SQL**, **GenAI** and
**System Design**. Each subject runs from the very beginning to interview
level, and each module closes with a short assessment.

## How it is organised

Every subject has the same shape, so you always know where you are:

```
subject → level → module → topic
```

- A **topic** is one page: 5 to 15 minutes of reading, one idea.
- A **module** is a small group of topics on one theme, ending in an assessment.
- A **level** groups modules by difficulty: basics, intermediate, advanced,
  then interview practice.

Use the sidebar to move around, or the search box if you already know what
you are looking for. Next and previous buttons at the bottom of every page
follow the reading order.

## Assessments

Each module ends with a short quiz. You get feedback and an explanation
immediately after every question, and a score at the end. The pass mark is
70%. Passing marks the module as complete.

**Your progress never leaves your browser.** There is no account, no login
and no server. Scores are stored in `localStorage`, which means:

- Progress is per browser and per device.
- Clearing site data resets it.
- Private windows start fresh every time.

## Who this is for

Readers preparing for interviews, developers filling a gap, and anyone who
prefers a book to a pile of tabs. No prior experience is assumed in the
basics levels.

## Contributing

This book is written in public and every chapter can be improved. If a
sentence is wrong, unclear, or missing, you can fix it — see
[Contributing](/docs/contributing). You do not need to know React to add a
topic: a topic is a Markdown file.
