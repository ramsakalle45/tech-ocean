## A worked example

```python
x = 10
y = x          # y refers to the same int object
x = 20         # rebinds x; y is untouched

print(x, y)    # 20 10
```

Names point at objects, they do not hold copies. `y = x` makes two names for one object; `x = 20` points `x` at a different object entirely.

<Callout type="interview" title="Interview corner">
**What does `a = b = []` do, and what is the trap?**

Both `a` and `b` refer to the *same* list. Appending to `a` also appends to `b`. The trap is assuming `a = b = []` creates two empty lists — it creates one, referenced twice. The same trap reappears with `[[]] * 3`, which builds one list three times over.
</Callout>

## Quick recap

- Assignment binds a name to an object; it never copies.
- Four scalar types cover most of what you will write: int, float, str, bool.
- `==` compares values, `is` compares identity — they are not interchangeable.
