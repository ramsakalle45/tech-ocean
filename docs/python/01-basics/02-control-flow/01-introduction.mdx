## Why it matters

Control flow is where a program stops being a list of steps and starts having behaviour. It is also where the bugs live: loops that never end, and branches that quietly skip work.

## A worked example

```python
for n in range(2, 10):
    if n % 2 == 0:
        continue
    if n > 7:
        break
    print(n)          # 3, 5, 7
```

Reach for `range` when you know the count, `while` when you know the condition. Mixing them up is the most common source of off-by-one errors.

<Callout type="interview" title="Interview corner">
**Why is `while True` often paired with `break` rather than a condition?**

Because it separates "how do I stop" from "when do I stop". The loop body reads linearly — process one item, decide whether to continue — instead of nesting the continuation test inside a compound condition. It also guarantees at least one pass, which `while condition` does not.
</Callout>

## Quick recap

- `for` iterates over something; `while` repeats until a condition changes.
- Every loop needs a termination argument. Write it down.
- `break` exits, `continue` skips to the next iteration, loop `else` runs when no `break` happened.
