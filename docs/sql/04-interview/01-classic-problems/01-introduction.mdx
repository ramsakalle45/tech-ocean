## What you will learn

- Write "top N per group" without a self-join
- Compute running totals and gaps with window functions
- Deduplicate keeping the most recent row
- Explain the trade-off between a CTE and a window function

## Why it matters

These specific questions appear constantly, and they are all variations on a handful of shapes: rank within a group, compare with a neighbour, and keep the latest.

## A worked example

```sql
WITH ranked AS (
    SELECT
        o.*,
        ROW_NUMBER() OVER (
            PARTITION BY o.customer_id
            ORDER BY o.placed_at DESC
        ) AS rn
    FROM orders AS o
)
SELECT *
FROM ranked
WHERE rn = 1;
```

The same shape answers "latest order per customer" and "top order per customer". Only the ordering changes.

<Callout type="interview" title="Interview corner">
**How do you find the top three products by revenue for each category?**

Aggregate revenue per product per category, then rank within the category with `ROW_NUMBER() OVER (PARTITION BY category ORDER BY revenue DESC)` and keep ranks 1 to 3. The partitioning column is the category; the ordering column is the revenue.
</Callout>

## Quick recap

- Most "per group" questions are a window function.
- Aggregate first, then rank — the other order is usually wrong.
- Use a deterministic tiebreaker so paging is stable.
