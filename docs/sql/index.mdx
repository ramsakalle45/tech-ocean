# SQL

Querying, modelling and tuning relational databases.

Every module ends with a short assessment. Progress is tracked in your
browser only — there is no account and no server.

## Roadmap

- **Basics** — Select and Filtering, Sorting and Aggregates, Ddl and Dml
- **Intermediate** — Joins, Subqueries and Ctes, Group By and Set Operations, Constraints
- **Advanced** — Window Functions, Indexes and Query Plans, Transactions and Isolation, Optimization and Partitioning
- **Interview** — Classic Problems, Query Challenges, Mock Tests

> This book is being written in public. Draft chapters are marked and open
> for contribution.
