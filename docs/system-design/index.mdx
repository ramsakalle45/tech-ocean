# System Design

Scaling, consistency and the classic case studies.

Every module ends with a short assessment. Progress is tracked in your
browser only — there is no account and no server.

## Roadmap

- **Fundamentals** — Scalability, Latency and Throughput, Cap and Consistency
- **Building Blocks** — Load Balancing, Caching, Queues, Databases and Sharding, Cdn and Api Design
- **Case Studies** — Url Shortener, Rate Limiter, Chat System, News Feed, Video Streaming, Notification System
- **Interview** — Framework, Estimation, Mock Designs
